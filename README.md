# 🌐 Personal Portfolio Website

## 📝 Description
This repository contains my personal portfolio website, which I am currently building to showcase my software development projects, technical skills, and academic journey. The site is designed to be clean, simple, and fully responsive across different screen sizes.

> 🛠️ **Status:** Work in progress. New sections and features are being added regularly.

---

## 🛠️ Tech Used
* **HTML5:** Used for building the structure and semantic layout of the pages.
* **CSS3:** Used for styling, custom layouts (Flexbox/Grid), and making the site responsive for mobile and desktop screens.

---

## 📁 What's inside this repository?
* **`index.html`** – The core webpage containing layout, sections, and portfolio content.
* **`style.css`** – The stylesheet responsible for the overall visual design, colors, and media queries.
* **`images/`** – Media files.
